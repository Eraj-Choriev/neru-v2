# API audit — 2026-11-20

Direct GET requests to both NERU map feeds returned HTTP 200. The current
parking response was compared record by record with
`api-baseline-2026-10-28.json`.

## Charging stations

- `getMarkerPower` returned 348 records; all 348 normalized successfully.
- All current records identify their city as Душанбе. The new IDs since the
  October snapshot are also Dushanbe locations; the feed contains no
  Турсунзода or other regional charging-station records yet.
- Compared with the October 28 station-ID baseline, 38 IDs are now present
  that were absent then, and 31 baseline IDs are absent now: a net increase
  of 7 records. The app already maps the full feed dynamically, so these IDs
  do not belong in a hardcoded station list.

## Paid parking

- `getMarkerParking` returned 243 raw records, field-for-field identical to
  the October 28 snapshot; 227 records have usable geometry and 16 do not.
- City values: 240 Душанбе and 3 н. Рӯдакӣ. No Турсунзода parking records are
  present in this feed yet.
- The full API feed has 4,147 spaces and 214 accessible spaces. The 227 zones
  with valid map geometry account for 3,881 spaces and 199 accessible spaces;
  the 16 unplotted rows account for the remaining 266 and 15.
- The map region picker groups all API rows by `city`. It shows each region's
  full zone, space and accessible-space counts, marks rows without usable
  geometry, filters map features to zones with coordinates, and includes a
  full-feed option. New API city values will appear without a code change.
